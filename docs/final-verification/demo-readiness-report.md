## 1. Quick Startup Commands

Launch both services simultaneously using the root launcher:
```powershell
.\start_all.bat
```
Or start individually in separate terminals:
- **Backend Gateway**:
  ```powershell
  .\start_backend.bat
  # Listens on http://localhost:8000 (Swagger docs at http://localhost:8000/docs)
  ```
- **Frontend Portal**:
  ```powershell
  .\start_frontend.bat
  # Serves at http://localhost:5173
  ```

## 3. Step-by-Step Live Judging Walkthrough

### Step 1: Zero-Trust Login & Lockout Protection (Screen 1)
1. Open browser to `http://localhost:5173`.
2. Point out the zero-trust banner: *"5-failure temporary lockout active"*.
3. Click the pre-seeded `analyst_user` chip and click **Sign In to Gateway**.

### Step 2: Gateway Dashboard & Health KPIs (Screen 2)
1. Showcase the 4 live KPI metric cards:
   - **Total Datasets**: `2` official sensitive partitions.
   - **Privacy Budget Used**: Animated gauge showing spent vs remaining epsilon $\epsilon$.
   - **Active Datasets**: `2` verified isolated vaults.
   - **Recent Actions**: Live ledger of audit-tracked operations.
2. Click **⚡ New Query** to transition to the Query Builder.

### Step 3: Dataset Catalog & Bounded Scope (Screen 3)
1. Show the searchable catalog containing `Healthcare Clinical Cohort` and `Retail Banking Suspicious Activity Transactions`.
2. Point out the metadata chips: `patient_id` privacy unit, 500 records, allowed query fields.

### Step 4: Restricted Grammar Query Builder & Live Preview (Screen 4)
1. Select field: `diagnosis` -> value: `Hypertension`.
2. Adjust the Privacy Parameter slider $\epsilon = 0.50$.
3. Point out the live SQL syntax box:
   ```sql
   SELECT COUNT(*) AS noisy_count
   FROM healthcare_vault
   WHERE diagnosis = 'Hypertension';
   ```
4. Note the green badge: `✓ Query is valid` with bounded sensitivity $\Delta f = 1.0$.
5. Click **⚡ Run Query**.

### Step 5: Loading Modal & Differential Privacy Output (Screen 12 & Screen 5)
1. Observe Screen 12 modal: *"Processing your query... Applying differential privacy and checking budget."*
2. View Screen 5 results:
   - **Noisy Count**: Real Laplace noise applied ($101$ or $104$ vs raw ground truth $100$).
   - **Confidence Interval**: 95% Laplace error bounds calculated and reported honestly.
   - **Privacy Budget Cost**: $0.50\ \epsilon$ deducted from the shared ledger.
3. Click **View Privacy Receipt**.

### Step 6: Verifiable Cryptographic Privacy Receipt (Screen 7)
1. Showcase Screen 7 receipt card:
   - Unique Receipt ID (`rcpt-...`).
   - Noise scale $b = 2.0$, epsilon $\epsilon = 0.50$.
   - SHA-256 hash pointer to previous audit block.
   - Ed25519 digital signature generated by the gateway keypair.
2. Click **Verify Signature** to show the live verification confirmation badge.
3. Click **Download Receipt** to export the verified JSON payload.

### Step 7: Privacy Budget Tracker & SVG Ring Meter (Screen 6)
1. Navigate to **Privacy Budget** in the sidebar.
2. Show the circular SVG ring meter reflecting exact consumption ($0.50 / 5.00\ \epsilon$).
3. Point out the ledger table recording timestamps and per-query costs.

### Step 8: Cryptographic Audit Hash Chain (Screen 8)
1. Navigate to **Audit Logs** in the sidebar.
2. Observe the green confirmation banner: `SHA-256 HASH CHAIN INTEGRITY VERIFIED (0 broken entries)`.
3. Explain how mathematical hash pointers prevent silent database tampering or retro-active modification.

### Step 9: Principle of Least Privilege & Security Alerts (Screen 10 & Screen 13)
1. As `analyst_user`, attempt to navigate to **User Management** in the sidebar.
2. Observe Screen 13: **Access Denied**: *"You do not have permission to access this resource: requires user.manage"*.
3. Log out and sign in as `admin_user` (`AdminPass2026!`).
4. Re-open **User Management** (Screen 10) to see all active/locked accounts and the **Unlock Account** control button.
