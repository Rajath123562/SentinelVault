4. REMAINING CLOUD DEPLOYMENT PROCEDURE (WHEN CREDENTIALS ARE PROVIDED)
--------------------------------------------------------------------------------
SentinelVault is container-ready and multi-cloud compliant:

Step 1: Container Build
  docker build -t sentinelvault-backend:latest -f backend/Dockerfile .
  docker build -t sentinelvault-frontend:latest -f frontend/Dockerfile .

Step 2: Environment Variables (.env)
  APP_ENV=production
  DATABASE_PATH=/var/data/hotfix_mvp.db
  APP_SECRET=<generate-secure-32-byte-hex>
  CORS_ORIGINS=https://sentinelvault.app,https://api.sentinelvault.app

Step 3: Deploy to Cloud Run / AWS ECS / Fly.io
  gcloud run deploy sentinelvault-api --image gcr.io/<PROJECT>/sentinelvault-backend:latest --port 8000
  gcloud run deploy sentinelvault-ui  --image gcr.io/<PROJECT>/sentinelvault-frontend:latest --port 80
